# Kono Pizza Ireland — VIP Premium Website

A presentation-first premium website concept researched around Kono Pizza Ireland's distinctive pizza-in-a-cone proposition.

## Research used
Public sources describe Kono Pizza Ireland as a Dublin-based concept built around portable cone-shaped pizza, with classic, salad and dessert options, vegan-friendly choices, and a mobile/event operation for festivals, weddings and corporate occasions. Press coverage also describes Italian dough, sauce and cheese and premium Irish toppings.

The supplied live domain was not directly crawlable in this environment, so the site deliberately avoids inventing current opening hours, current prices, or current store availability. Demo prices are clearly marked in the menu copy and should be replaced with verified live data before launch.

## Included
- Premium dark editorial UI
- Red/blue/green accent treatment
- Original generated food photography stored locally
- Delivery / Collection journey
- Eircode UI
- Menu filters
- Working demo cart
- Left/right/up reveal animations
- Marquee animation and hover effects
- Catering/event section
- Locations section
- Mobile responsive design
- GitHub Pages-ready, no build step

## Deploy
Upload all files to a GitHub repository and enable GitHub Pages from the repository's Pages settings. Open `index.html` locally for a quick preview.

## Production checklist
Connect the live Kono ordering system, verify menu/prices/locations/opening hours, confirm the correct catering contact details, and replace demo photography with Kono-approved photography if desired.
